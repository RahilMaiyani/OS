Type 1: Contiguous Partition Allocation (First, Best, Worst, Next Fit) Unit 6
📌 Points to Remember & Algorithm Rules
  • First-Fit: Allocate the first partition that is big enough ($\ge$ process size). Fastest allocation, but clutters small holes at beginning.
  • Best-Fit: Allocate the smallest partition that is big enough. Leaves the smallest leftover hole. Most space-efficient for large upcoming jobs.
  • Worst-Fit: Allocate the largest available partition. Leaves the largest leftover hole. Often leads to poor utilization.
  • Next-Fit: Starts search from where the last allocation was made rather than restarting from the beginning.

Type 3: Paging with TLB & Effective Memory Access Time (EMAT) PB Q223, Q224, Q227
📌 Formulas & Points to Remember
Hit Ratio = α, Miss Ratio = (1 - α)
• Without TLB Search Time: EMAT = [ α × t_mem ] + [ (1 - α) × (t_page_table + t_mem) ]
• With TLB Search Time (t_tlb): EMAT = [ α × (t_tlb + t_mem) ] + [ (1 - α) × (t_tlb + t_page_table + t_mem) ]

Why? On a TLB hit, data is accessed directly in 1 memory cycle. On a TLB miss, CPU must first read the page table in memory, and then read the actual data (2 memory accesses).

PB Q223: Without TLB Search Overhead

Hit ratio = 75%, Memory = 100ns, Page Table = 100ns.

• Hit (75%): 100 ns
• Miss (25%): 100 + 100 = 200 ns
EMAT = 0.75 × 100 + 0.25 × 200 = 75 + 50 = 125 ns
PB Q224: Asymmetrical Timing

Hit ratio = 85%, Memory = 100ns, Page Table = 50ns.

• Hit (85%): 100 ns
• Miss (15%): 50 + 100 = 150 ns
EMAT = 0.85 × 100 + 0.15 × 150 = 85 + 22.5 = 107.5 ns
PB Q227: With 20ns TLB Lookup Time

Hit ratio = 75%, Memory = 100ns, Page Table = 100ns, TLB = 20ns.

• Hit (75%): 20 + 100 = 120 ns
• Miss (25%): 20 + 100 + 100 = 220 ns
EMAT = 0.75 × 120 + 0.25 × 220 = 90 + 55 = 145 ns
Type 4: Logical Address to Physical Address Translation PB Q239
📌 Formula & Steps
Page Number (p) = Logical Address / Page Size
Page Offset (d) = Logical Address % Page Size
Physical Address = (Frame Number f × Page Size) + Offset d
Solved Example: Given Logical Address = 5000, Page Size = 1024 bytes (1 KB). Page Table maps Page 4 → Frame 7.
• $p = 5000 / 1024 = 4$
• $d = 5000 \pmod{1024} = 904$
• Physical Address = $(7 \times 1024) + 904 = 7168 + 904 = \mathbf{8072}$.
Chapter 7: Virtual Memory & Page Replacement Numericals Unit 7
📌 Points to Remember & Algorithm Shortcuts
  • FIFO: Replace the oldest loaded page in the frame. Susceptible to Belady's Anomaly (page faults can increase with more frames).
  • LRU: Look backwards in the reference history; replace the page that was referenced least recently. (Optimal practical approximation).
  • Optimal (OPT): Look forward into the future; replace the page that will not be referenced for the longest duration. (Theoretical minimum faults).
  • NRU (Not Recently Used): Uses Reference bit ($R$) and Modified bit ($M$). Four classes: Class 0 $(R=0, M=0)$, Class 1 $(R=0, M=1)$, Class 2 $(R=1, M=0)$, Class 3 $(R=1, M=1)$. Replaces from the lowest non-empty class.
  • Second Chance: Inspects FIFO with bit $R$. If $R=1$, clear to $0$ and give second chance; if $R=0$, evict.

Chapter 8: Disk Scheduling All 6 Algorithms & Seek Time Unit 8
📌 Points to Remember & Formulas
Total Head Movement (THM) = Sum of absolute cylinder differences: Σ |Current - Next|
Total Seek Time = THM × (Seek Time per cylinder)
Rotational Latency = 1 / (2 × RPM) × 60 seconds
  • FCFS: Services in arrival queue order.
  • SSTF: Greedily selects the closest pending cylinder. Minimum seek time, but risk of starvation for distant requests.
  • SCAN: Moves towards one extreme (touches track 0 or Max track), then reverses.
  • LOOK: Moves towards one extreme only up to the last pending request (does NOT travel to boundary 0 or Max).
  • C-SCAN: Moves to boundary, jumps to opposite boundary without servicing, continues in same direction.
  • C-LOOK: Moves to last request in direction, jumps to lowest request without servicing, continues.

Complete Core Theory Guide (Chapters 6 to 10) Exam Ready
Internal vs External FragmentationCh 6
  • Internal Fragmentation: Memory allocated to process is larger than requested; unused memory inside allocated partition is wasted (Fixed partitioning & Paging).
  • External Fragmentation: Total free space exists but is broken into non-contiguous holes scattered across RAM (Variable partitioning & Segmentation).
  • Remedies: Compaction shuffles memory contents to merge free holes. Paging completely eliminates external fragmentation.
Paging vs SegmentationCh 6
  • Paging: Hardware memory management dividing process into fixed-size pages and physical RAM into frames. Transparent to programmer. Suffers from internal fragmentation.
  • Segmentation: Logical division according to programmer's view into variable-size segments (code, stack, data, heap). Suffers from external fragmentation.
  • Paging uses a Page Table (page → frame); Segmentation uses a Segment Table (base & limit).
Demand Paging & Page Fault StepsCh 7
  • Demand Paging: Pages are loaded into RAM only when demanded during execution (Lazy Swapper).
  • Page Fault Handling (6 Steps): 1. CPU traps to OS on accessing unmapped page.
    2. Save CPU registers and process state.
    3. Check page table; determine page location on backing store.
    4. Find a free frame (or run replacement algorithm).
    5. Schedule disk I/O to read page into frame.
    6. Update page table valid bit & restart interrupted instruction.
Thrashing: Causes & RemediesCh 7
  • Definition: A pathological state where the OS spends more time swapping pages than executing instructions, dropping CPU utilization to near zero.
  • Cause: Too high a degree of multiprogramming. Allocated frames fall below the process's Working Set.
  • Remedies: 1. Working Set Model: Keep total working set pages in RAM.
    2. Page Fault Frequency (PFF): Suspend/swap out processes when page fault frequency crosses upper threshold.
Seek Time, Rotational Latency & DMACh 8
  • Seek Time: Time taken by read/write head assembly to travel to designated cylinder.
  • Rotational Latency: Time for target platter sector to rotate under head.
  • Transfer Time: Time required to physically stream data to/from disk.
  • Direct Memory Access (DMA): Specialized controller transferring blocks between I/O device and RAM without continuous CPU intervention, freeing CPU for tasks.
8 Design Principles of SecurityCh 9 · High Probability
1. Least Privilege: Subject given only minimum rights to complete task.
2. Fail-Safe Defaults: Default access to any object is none (denied).
3. Economy of Mechanism: Design must be simple and small to minimize errors.
4. Complete Mediation: Every single access checked by OS every time.
5. Open Design: Security must not depend on secret algorithms; open design.
6. Separation of Privilege: Multiple conditions needed to grant access.
7. Least Common Mechanism: Minimize mechanisms shared among users.
8. User Acceptability: Mechanism must be easy to use; otherwise bypassed.
ACL vs Capability ListCh 9
  • Access Control List (ACL): Slicing matrix by COLUMNS (attached to File). Lists domains/users and rights. Advantage: Easy revocation. Disadvantage: Slower lookups.
  • Capability List (C-List): Slicing matrix by ROWS (attached to Process). Lists objects and permitted rights. Advantage: Instant access checks. Disadvantage: Hard revocation.
Linux Kernel Subsystems & FeaturesCh 10
  • System Call Interface: User mode traps into kernel mode.
  • I/O Component: VFS, Character & Block drivers (with I/O Scheduler), Network sockets.
  • Memory Component: Virtual memory, paging/replacement, page cache.
  • Process Component: Creation/exit (fork, exit), signals, CPU scheduler.
  • Unix Features: Multiuser, Multitasking, Everything is a file, Portable C code.

2. Reverse of a Given Number (Practical-14 / Q346) 
# Practical-14: Reverse of given number using while loop
echo "Enter the number: "
read n
rev=0
while [ $n -gt 0 ]
do
  sd=$(expr $n % 10)
  rev=$(expr $rev \* 10 + $sd)
  n=$(expr $n / 10)
done
echo "Reverse number is $rev"
3. Check Whether Number is Prime (Practical-17 / Q348) 
# Practical-17: Prime number check
echo "Enter a number: "
read num
i=2
f=0
while [ $i -le `expr $num / 2` ]
do
  if [ `expr $num % $i` -eq 0 ]
  then
    f=1
  fi
  i=`expr $i + 1`
done
if [ $f -eq 1 ]; then echo "Composite number"
else echo "Prime number"; fi
4. Armstrong Number Check (Practical-15 / Q347) 
# Practical-15: Armstrong number (e.g. 153 = 1^3 + 5^3 + 3^3)
echo "Enter number: "; read c
x=$c; sum=0
while [ $x -gt 0 ]
do
  r=`expr $x % 10`
  n=`expr $r \* $r \* $r`
  sum=`expr $sum + $n`
  x=`expr $x / 10`
done
if [ $sum -eq $c ]; then echo "Armstrong Number"
else echo "Not Armstrong Number"; fi

6. Palindrome String using Character Extraction (Practical-28 / Q349) 
# Practical-28: Palindrome string using cut -c
clear
echo "Enter string: "; read str
len=`echo $str | wc -c`
len=`expr $len - 1`
i=1
j=`expr $len / 2`
while [ $i -le $j ]
do
  k=`echo $str | cut -c $i`
  l=`echo $str | cut -c $len`
  if [ "$k" != "$l" ]
  then
    echo "String is NOT palindrome"
    exit
  fi
  i=`expr $i + 1`
  len=`expr $len - 1`
done
echo "String IS palindrome"
7. Sort Array of Numbers in Ascending Order (Practical-20 / Q350) 
# Practical-20: Array Bubble sort
clear
echo "Enter number of elements: "; read n
echo "Enter array elements: "
for (( i=0; i<n; i++ )); do read a[$i]; done
for (( i=0; i<n; i++ ))
do
  for (( j=$i; j<n; j++ ))
  do
    if [ ${a[$i]} -gt ${a[$j]} ]
    then
      temp=${a[$i]}
      a[$i]=${a[$j]}
      a[$j]=$temp
    fi
  done
done
echo "Array after sorting: "
for (( i=0; i<n; i++ )); do echo ${a[$i]}; done
